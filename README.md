# Alimbio Directory

Company directory application, example for an agri-food business.

## Features

- Employee and site directory
- C# / ASP.NET

## Tech Stack

- C# / .NET

## Getting Started

```bash
git clone https://github.com/ghostland-dev/alimbio-directory.git
cd alimbio-directory
dotnet restore
dotnet run
```
